# Source material — the uploaded originals

The primary documents this project's rules were extracted from, preserved so
nothing is lost if a working session is reclaimed.

## Contents
- `instructor_pdfs/` — the Sutra-of-Waves (SOW) / NeoWave course materials by
  Ashish Kyal / Waves Strategy Advisors: the 92-page "Neo Wave with Ichimoku
  Cloud" training deck, the Day-1 / Day-2 handwritten notes, the Day-2 Fibo
  sheet, and the Brahmastra mentorship pages.
- `zip_archives/` — the project bundles as uploaded: the md/TradingView-playbook
  pack, the research-validation pack, the automation SPEC + agent-prompt packs,
  the legacy-repo usage/roadmap pack, the existing-repo audit pack, and a
  snapshot zip of an earlier state of this repo.
- `ledger_extracts/` — the intermediate per-pack rule extractions
  (`extract_*.md`) produced by the reader agents; `scripts/build_rules_ledger.py`
  merges these into `docs/RULES_LEDGER.md`.

## Derived, searchable versions live elsewhere in the repo
- `docs/RULES_LEDGER.md` — every rule/setup/explanation, 581 numbered entries.
- `docs/research/SOW_METHOD.md` — the instructor's method, page-cited.
- `docs/research/sow_deep_read/` — page-by-page transcriptions of the PDFs.
- `docs/atlas/SOW_PATTERN_ATLAS.html` — original diagrams for every pattern.

These are the author's copyrighted course materials, retained here for this
project's own reference. Treat this directory as private; do not redistribute.
